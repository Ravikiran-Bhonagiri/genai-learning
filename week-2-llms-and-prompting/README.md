# 🗣️ Week 2: The Art of Speaking to Machines (Prompting)

Last week, you looked inside the mind of the machine. This week, we learn to speak its language. 

We aren't just talking about saying "please" to a chatbot or adding "think step by step" to the end of a sentence. We are elevating prompt engineering from a social media party trick to a rigorous, systematic software engineering discipline. 

Can you make an unpredictable LLM reliably output perfectly structured JSON every single time? Can you force a model to debate itself, double-check its own logic, and correct its mistakes before returning an answer to the user? Can you literally program a model to write programs?

Welcome to the cutting edge of human-computer interaction. The prompts you write this week are the source code of the future.
